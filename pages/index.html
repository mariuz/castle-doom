Castle DOOM

Doom levels, rendered and played with Castle Game Engine. Freedoom Phase 1 & 2 included.

Play in the browser Download for Windows / Linux

The desktop builds can load your own IWADs and PWADs (menu or -iwad / -file). The browser version downloads about 90 MB (two WADs plus the engine) and needs WebGL 2. Click the canvas to capture the mouse.

Controls

WASD / arrows move, Shift run, mouse look, left mouse / Ctrl fire, E / Space use (doors, switches), 1-7 and wheel weapons, F light diminishing, M mouse look on/off, J music on/off, Tab automap (+/- zoom, G grid), F2 / F3 save / load (F6 / F9 quick), N / P next / previous map, H help, Esc menu. Title menu: arrows and Enter (or the mouse), Esc back; Options picks the WAD, map and skill. Saves are kept in your browser's local storage for this site.

How Doom maps onto the engine

DoomCastle Game Engine
WAD lumps, BSP nodes, subsectorsPlain Pascal records; convex subsector polygons recovered by clipping against the BSP partition lines
Walls, floors, ceilings, sector lightX3D nodes built in code: IndexedTriangleSet, UnlitMaterial, per-vertex Color; one scene per movable sector
Textures, flats, spritesDecoded from patches, served through a custom doomgfx: URL protocol so the engine's texture cache shares them
Sky, light diminishingCamera-following textured cylinder; Doom's colormap arithmetic per pixel as a GLSL shader effect (TEffectNode, a FloatVertexAttribute with the sector light)
PlayerTCastleWalkNavigation with gravity, step climbing and precise collisions
Things, monstersTCastleBillboard sprites with Doom's 8-rotation selection; 2D Doom-style movement rules
ShootingWorldRay ray casts against walls and sprites
Doors, lifts, floors, crushers, stairs, teleportersSector heights change and the affected scenes are regenerated in place
SoundsDMX lumps converted to WAV on the fly (doomsfx: protocol), positional with TCastleSoundSource
MusicMUS / MIDI lumps played by an OPL2-style FM synthesizer using the WAD's GENMIDI patches, rendered to a looping WAV
